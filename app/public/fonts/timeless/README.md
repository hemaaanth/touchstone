# Timeless Sans (Grotesk cut)

- Source: the vendor's own web embedding file, served at https://timeless.co/type.
- File: `TimelessSansVF.woff2`, version 1.094. Axes: wght 300–800, ital 0–100, STYL 0–100.
- STYL 0 is the Grotesk cut. It is also the default axis value.
- The app registers this file as the CSS family "Timeless Grotesk" (see `src/fonts.css`).
- License: Timeless Free Font License 1.2 (`timeless-free-font-license-1.2.pdf`). The font file names this version.
  Section 5.3 allows embedding in apps and keeping the file in the code repository.
  Section 5.5 requires this license copy next to the file.
- Do not modify, rename, or redistribute the file on its own. Do not use it to train AI models.
- To use the official download package instead, request it at https://timeless.co/type (it asks for an email address).
